## 三个通用判断

1. **「装不上」和「连不上」是两个问题。** 前者看系统版本与权限，后者看 TLS 与出口。
2. **固定间隔掉线是定时器，随机掉线是网络路径。** 记三次时间点就能分辨。
3. **更新前留一份旧安装包。** 版本号可以再看，被覆盖的安装包找不回来。
